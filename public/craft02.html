📚 About This Tool

This explorer connects you to free, web-based cognitive skill activities designed for Grade 7 students. These resources help assess and develop:

  • Memory: Visual, verbal, and working memory
  • Numeracy: Math fluency, number sense, and problem-solving
  • Logic: Reasoning, pattern recognition, and critical thinking
  • Processing Speed: Reaction time and information processing
  • Language: Vocabulary and reading comprehension
  • Executive Function: Planning, decision-making, and cognitive flexibility

No API keys required! All resources load directly in your browser.
